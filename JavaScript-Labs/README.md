## 4. Nội dung thực hiện từng Lab

### Lab 08 – JavaScript 1: Introduction
- Làm quen với JavaScript và cách nhúng JavaScript vào HTML.
- Thực hành các kiến thức cơ bản về String, Date, Math, Array, Function và Object.
- Làm quen với việc kiểm tra kết quả thông qua Browser Console.

### Lab 09 – JavaScript 2
- Tiếp tục thực hành và củng cố kiến thức JavaScript.
- Vận dụng các cú pháp, kiểu dữ liệu và cách xử lý dữ liệu thông qua các bài tập.
- Rèn luyện khả năng sử dụng JavaScript để giải quyết các yêu cầu lập trình.

### Lab 10 – JavaScript 3: jQuery
- Làm quen với thư viện jQuery.
- Thực hành lựa chọn phần tử, thao tác DOM và xử lý sự kiện.
- Tạo hiệu ứng chuyển động cho các phần tử trên website.
- Tìm hiểu cách gửi yêu cầu GET và xử lý dữ liệu bất đồng bộ.
