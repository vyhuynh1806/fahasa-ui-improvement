Bài tập cá nhân Buổi 2 tiếp tục phát triển và hoàn thiện giao diện website đã thực hiện ở Buổi 1.

Trong buổi này, tôi tập trung thực hành HTML5 và CSS3 thông qua việc xây dựng cấu trúc HTML, sử dụng CSS Selector, Box Model và bố cục Flexbox hoặc CSS Grid ở mức cơ bản.

**Thông tin dự án:**

- **Tên website:** FAHASA – Nhà sách trực tuyến.
- **Chủ đề:** Website thương mại điện tử chuyên kinh doanh và giới thiệu sách.
- **Công nghệ sử dụng:** HTML5, CSS3.
- **Hình thức thực hiện:** Bài tập cá nhân.

## 2. Website tham khảo và khu vực cải tiến

- **Website tham khảo:** FAHASA – Nhà sách trực tuyến (https://www.fahasa.com/).
- **Khu vực được lựa chọn:** Khu vực thông tin chi tiết sản phẩm, thanh điều hướng thông tin sách và chân trang (Footer).
- **Nội dung cải tiến:** Tiếp tục hoàn thiện giao diện website bằng cách điều chỉnh bố cục, khoảng cách giữa các thành phần, cách trình bày thông tin sản phẩm và thiết kế lại khu vực Footer. Bổ sung thanh điều hướng giúp người dùng dễ dàng di chuyển đến các phần thông tin như Tổng quan, Mô tả, Thông tin sách và Đánh giá.

## 3. Những kỹ thuật HTML5/CSS3 đã thực hành

Trong quá trình thực hiện, tôi đã áp dụng các kỹ thuật sau:

**HTML5:**

- Sử dụng các thẻ HTML5 để xây dựng cấu trúc nội dung website.
- Sử dụng các thẻ Semantic HTML như `header`, `nav`, `main`, `section`, `article` và `footer` để phân chia các khu vực giao diện.
- Sử dụng các thẻ liên kết `a` để tạo điều hướng giữa các phần nội dung.
- Tổ chức các thành phần nội dung theo cấu trúc hợp lý, dễ quản lý và chỉnh sửa.

**CSS3:**

- **CSS Selector:** Sử dụng các bộ chọn như class, element và descendant selector để áp dụng kiểu dáng cho từng thành phần HTML.
- **Box Model:** Thực hành các thuộc tính `margin`, `padding`, `border` và `width` để điều chỉnh kích thước và khoảng cách giữa các thành phần.
- **Flexbox:** Sắp xếp và căn chỉnh các thành phần trong Header, thanh điều hướng và Footer.
- **CSS Grid:** Sử dụng bố cục dạng lưới để sắp xếp các thẻ sản phẩm và các cột thông tin trong Footer.
- **Hover và Focus:** Bổ sung hiệu ứng tương tác cho các nút bấm và liên kết nhằm cải thiện trải nghiệm người dùng.

## 4. Hướng dẫn chạy website

**Yêu cầu:**

- Trình duyệt web: Google Chrome hoặc trình duyệt tương đương.
- Visual Studio Code (khuyến nghị).

**Các bước thực hiện:**

1. Clone repository về máy:
   ```bash
   git clone [Đường dẫn repository GitHub của bạn]
   ```
2. Mở thư mục dự án bằng Visual Studio Code.
3. Mở file `index.html` bằng trình duyệt hoặc sử dụng extension Live Server để chạy website.

## 5. Những thay đổi đã thực hiện

So với phiên bản Buổi 1, tôi đã thực hiện những thay đổi sau:

- Hoàn thiện khu vực thông tin chi tiết sản phẩm, giúp nội dung được trình bày rõ ràng và dễ theo dõi hơn.
- Bổ sung thanh điều hướng thông tin sản phẩm gồm Tổng quan, Mô tả, Thông tin sách và Đánh giá.
- Thiết kế lại khu vực Footer thành nhiều cột, bao gồm giới thiệu website, hỗ trợ khách hàng, danh mục sách và thông tin liên hệ.
- Điều chỉnh khoảng cách giữa logo và nội dung giới thiệu trong Footer để bố cục cân đối hơn.
- Cải thiện cách căn chỉnh, kích thước, màu sắc và khoảng cách giữa các thành phần giao diện nhằm giúp website trực quan và dễ sử dụng hơn.
